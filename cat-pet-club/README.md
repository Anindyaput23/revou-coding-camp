# 🐾 Cat Pet Club

A tiny cozy cat clicker game built with only:

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript

## Run it

Open `index.html` directly in a modern browser.

No build step or server is required.

## Features

- Click the cat or the **PET THE CAT 🐾** button
- Pet counter
- Random cat reactions
- Multiple cat expressions
- Floating `+1 🐾` feedback
- Rare reactions with sparkle effects
- Responsive layout
- Keyboard-accessible interaction
- Reduced-motion support
- No external JavaScript frameworks

## Files

```text
cat-pet-club/
```

## Note

Tailwind CSS and Nunito are loaded from CDNs, so those external resources need internet access when the page is opened. The app's JavaScript and cat illustration are local.
